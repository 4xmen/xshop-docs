# راهنمای مدیریت سرفصل‌ها (Group)

## معرفی صفحه

سرفصل‌ها (Group) برای گروه‌بندی و سازمان‌دهی نوشته‌های سایت استفاده می‌شوند. هر سرفصل می‌تواند نام، زیرعنوان، توضیحات، تصویر و تنظیمات مربوط به نمایش و سئوی خود را داشته باشد. همچنین امکان ایجاد ساختار والد و زیرسرفصل وجود دارد.

صفحه‌ی ویرایش سرفصل به شما امکان می‌دهد اطلاعات سرفصل را مدیریت کنید، ظاهر آن را در بخش‌های پشتیبانی‌شده‌ی قالب تنظیم کنید و در صورت نیاز، Schema Markup مربوط به نوشته‌های مرتبط یا صفحه‌ی خود سرفصل را تعریف کنید.

تصویر ۱ ـ نمای صفحه‌ی ویرایش سرفصل (Edit group) و بخش‌های شماره‌گذاری‌شده‌ی آن.

## ۱. اطلاعات عمومی سرفصل (Group)

این بخش برای مدیریت اطلاعات اصلی سرفصل استفاده می‌شود.

| فیلد         | کاربرد                                                                                                                                    |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------------- |
| Group name   | نام سرفصل را مشخص می‌کند.                                                                                                                 |
| Group slug   | شناسه‌ی متنی مورد استفاده در آدرس سرفصل است. طبق راهنمای پنل، اگر این فیلد خالی باشد، مقدار آن به‌صورت خودکار تولید می‌شود.               |
| Subtitle     | زیرعنوان سرفصل را مشخص می‌کند.                                                                                                            |
| Group Parent | سرفصل والد را برای ایجاد ساختار سلسله‌مراتبی انتخاب می‌کند. در صورت نداشتن والد، گزینه‌ی `No parent` انتخاب می‌شود.                       |
| Hide in menu | مشخص می‌کند سرفصل در منوهایی که زیرسرفصل‌ها را نمایش می‌دهند، مخفی شود یا خیر. این گزینه به‌تنهایی به معنی غیرفعال شدن صفحه‌ی سرفصل نیست. |
| Description  | توضیحات سرفصل را ثبت می‌کند. این قسمت از ویرایشگر متنی برای نگارش و قالب‌بندی محتوا استفاده می‌کند.                                       |

نام، زیرعنوان و توضیحات سرفصل از محتوای چندزبانه پشتیبانی می‌کنند.

نکته: برای قرار دادن یک سرفصل در زیرمجموعه‌ی سرفصل دیگر، مقدار مناسب را در فیلد `Group Parent` انتخاب کنید. اگر سرفصل اصلی است، می‌توانید آن را بدون والد نگه دارید.

## ۲. تصویر شاخص (Feature image)

این بخش برای انتخاب تصویر اصلی سرفصل است. تصویر شاخص می‌تواند در فهرست‌ها یا بخش‌هایی از سایت که قالب برای نمایش سرفصل از تصویر استفاده می‌کند، نمایش داده شود.

برای انتخاب تصویر، از گزینه‌ی بارگذاری فایل در این قسمت استفاده کنید.

## ۳. تصویر پس‌زمینه (Background image)

در این قسمت می‌توانید تصویر پس‌زمینه‌ی سرفصل را انتخاب کنید. این تصویر در برخی قالب‌ها و حالت‌های طراحی قابل استفاده است.

نمایش تصویر پس‌زمینه به پشتیبانی قالب از این قابلیت بستگی دارد؛ بنابراین، انتخاب تصویر لزوماً به معنی نمایش آن در تمام صفحات یا بخش‌های سایت نیست.

## ۴. پیوست‌ها (Attachments)

این بخش برای مدیریت پیوست‌های مرتبط با سرفصل است.

با استفاده از دکمه‌ی افزودن پیوست می‌توانید فرایند اضافه کردن پیوست را آغاز کنید. عدد کنار دکمه، تعداد پیوست‌های نمایش‌داده‌شده در این بخش را نشان می‌دهد.

انواع پیوست‌های قابل استفاده و نحوه‌ی نمایش آن‌ها به قابلیت‌های مربوط به پیوست‌ها در پنل بستگی دارد.

## ۵. آدرس Canonical

فیلد `Canonical` برای ثبت آدرس مرجع صفحه‌ی سرفصل در تنظیمات سئو استفاده می‌شود.

این آدرس به موتورهای جست‌وجو کمک می‌کند نسخه‌ی مرجع صفحه را تشخیص دهند؛ به‌ویژه زمانی که صفحات مشابه یا آدرس‌های متفاوت با محتوای یکسان وجود دارند.

نکته: آدرس واردشده باید با صفحه‌ای که قصد معرفی آن به‌عنوان نسخه‌ی مرجع را دارید، مطابقت داشته باشد.

## ۶. تنظیم قالب اختصاصی سرفصل

دکمه‌ی خاکستری‌رنگ کنار عنوان صفحه، با آیکون پالت رنگ، برای دسترسی به تنظیمات قالب اختصاصی سرفصل در نظر گرفته شده است.

این قابلیت برای تنظیم ظاهر سرفصل به‌صورت اختصاصی کاربرد دارد و می‌تواند امکان متمایز کردن ظاهر آن از قالب عمومی سایت را فراهم کند.

تنظیمات این بخش مخصوص همان سرفصل است. جزئیات گزینه‌ها و نحوه‌ی اعمال هر تنظیم به امکانات صفحه‌ی تنظیم قالب بستگی دارد.

## Schema Markup

در صفحه‌ی ویرایش سرفصل، دو ویرایشگر Schema Markup وجود دارد که هرکدام کاربرد جداگانه‌ای دارند:

### Schema Markup نوشته‌های این سرفصل

ویرایشگر اول با عنوان `Markup schema for posts of this group` برای تعریف Schema Markup پیش‌فرض نوشته‌های مرتبط با سرفصل استفاده می‌شود؛ در صورت استفاده از این تنظیم توسط منطق برنامه.

### Schema Markup صفحه‌ی سرفصل

ویرایشگر دوم با عنوان `Markup schema` برای تعریف Schema Markup مربوط به خود صفحه‌ی سرفصل استفاده می‌شود.

در هر دو بخش، امکان وارد کردن کد Schema و استفاده از متغیرهای قابل‌جایگزینی وجود دارد. همچنین می‌توان چند اسکیما را در یک ویرایشگر قرار داد.

برای آشنایی با نحوه‌ی درج متغیرها، استفاده از دکمه‌های بالای ویرایشگر، انتخاب Syntax و عملکرد دکمه‌ی Reset، به مستندات راهنمای استفاده از ویرایشگر Schema Markup مراجعه کنید.

## ذخیره‌ی تغییرات

پس از تکمیل اطلاعات و تنظیم بخش‌های موردنیاز، روی دکمه‌ی Save در پایین صفحه کلیک کنید.

پیش از ذخیره، بهتر است نام و آدرس سرفصل، سرفصل والد، تصاویر، آدرس Canonical و تنظیمات Schema Markup را بررسی کنید تا با هدف موردنظر شما مطابقت داشته باشند.
