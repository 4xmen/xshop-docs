# سطح دسترسی کاربران سامانه

دسترسی کاربران به صورت سیستم مدیریت سطح دسترسی یعنی ACL (Access control layer) کار می‌کند.

اما ما سه سطح کلی در کاربران داریم:

- Developer
- Admin
- User

هیچ کاربری حق ویرایش سطح بالاتر از خودش را ندارد. مثلا مدیر نمی‌تواند توسعه‌دهنده را تعویض ویرایش کند.

# Developer
یعنی توسعه دهنده سایت سطح دسترسی کامل ۱۰۰٪ روی سایت دارد، لذا دسترسی developer را به همه مدیران حتی مدیر ارشد واگذار نکنید

# Admin 

دسترسی مدیر به صورت کلی سطح اختیارات زیادی دارد به جز موراد بسیار حساس که نیاز نیست مدیر به آنها دسترسی داشته باشد:

- تغییرات در زبان سایت
- تنظیمات ظاهر و رنگ بندی سایت
- طراحی قالب سایت

سایر دسترسی ها برای مدیر باز است.

# User

کاربر عادی است که سطح دسترسی آن توسط مدیران مشخص می‌شود، تمام دسترسی ها قابلیت سطح دسترسی در سیستم قابلیت ویرایش را دارد.
