# Helper functions

توابع helper برای ساده کردن کار توسعه دهنده‌ها مورد استفاده قرار می‌گیرد و این توابع هم در پنل ادمین و هم در سمت بازدید کننده در دسترس هستند و معمولا در controller یا blade استفاده می‌شوند.

## langIsRTL
این تابع برای تشخیص این که tag زبانی راست به چپ هست یا نه به کار می‌رود
مقدار آن boolean است و نمونه استفاده از آن:

```php
if (langIsRTL("fa"))
```

ورودی $langCode تگ زبان است.


## getEmojiLanguagebyCode

این تابع با دریافت کد زبان، ایموجی پرچمِ تعریف‌شده برای آن را برمی‌گرداند. اگر کد زبان در آرایه نباشد، `❓` برمی‌گرداند؛ نوع خروجی همیشه `string` است.

ورودی `$lang` کد زبان است، مانند `fa`. نمونهٔ استفاده:

```php
$emoji = getEmojiLanguagebyCode('vi');
```

## sortSuffix

این تابع برای تولید پسوند پارامتر مرتب‌سازی (Sort) در لینک‌های جدول استفاده می‌شود.

اگر ستون موردنظر با ستون مرتب‌سازی فعلی (`sort`) یکسان باشد، جهت مرتب‌سازی را معکوس می‌کند:

- اگر مرتب‌سازی فعلی `desc` باشد، مقدار `&sortType=asc` برمی‌گرداند.
- اگر مرتب‌سازی فعلی `asc` باشد یا تنظیم نشده باشد، مقدار `&sortType=desc` برمی‌گرداند.
- اگر ستون موردنظر با ستون مرتب‌سازی فعلی متفاوت باشد، رشته خالی برمی‌گرداند.

نوع خروجی: `string`

پارامتر ورودی:

- `$col`: نام ستونی که قرار است مرتب‌سازی بر اساس آن انجام شود.

نمونه استفاده:



```php
<a href="?sort=name{{ sortSuffix('name') }}">Name</a>
```

## arrayNormalizeVueCompatible

این تابع یک آرایه را به ساختاری سازگار با Vue تبدیل می‌کند تا استفاده از آن در کامپوننت‌های Vue و نمایش گزینه‌های قابل انتخاب ساده‌تر باشد.

هر عضو آرایه به یک آرایه انجمنی با دو کلید `id` و `name` تبدیل می‌شود:

- `id`: کلید اصلی عضو در آرایه ورودی.
- `name`: مقدار عضو که در صورت فعال بودن ترجمه، با تابع `__()` ترجمه می‌شود.

در نهایت خروجی به فرمت JSON تبدیل می‌شود.

نوع خروجی: `string|false`

پارامترهای ورودی:

- `$array`: آرایه ورودی.
- `$translate`: در صورت `true` بودن، مقادیر آرایه قبل از تبدیل به JSON ترجمه می‌شوند. مقدار پیش‌فرض `false` است.

نمونه استفاده:


```php
$options = arrayNormalizeVueCompatible([
    'fa' => 'Persian',
    'en' => 'English',
], true);
```

خروجی:


```json
[
    {"id": "fa", "name": "Persian"},
    {"id": "en", "name": "English"}
]
```

## isJson

این تابع بررسی می‌کند که آیا رشته ورودی یک JSON معتبر است یا خیر.

با استفاده از `json_decode` محتوای ورودی بررسی شده و در صورت نبود خطای JSON، مقدار `true` برگردانده می‌شود.

نوع خروجی: `bool`

پارامتر ورودی:

- `$string`: رشته‌ای که اعتبار JSON آن باید بررسی شود.

نمونه استفاده:



```php
if (isJson('{"name":"John"}')) {
    // Valid JSON
}
```

## logAdminBatch

این تابع برای ثبت لاگ عملیات گروهی (Batch) در پنل مدیریت استفاده می‌شود.

برای هر شناسه موجود در آرایه `$ids` یک رکورد لاگ در رابطه `logs` کاربر احراز هویت‌شده ایجاد می‌کند.

نام عملیات از بخش پایانی نام کلاس یا متد ارسال‌شده در `$method` استخراج می‌شود و اطلاعات زیر در لاگ ذخیره می‌شوند:

- `action`: نام عملیات.
- `loggable_type`: نوع مدل مرتبط با عملیات.
- `loggable_id`: شناسه رکوردی که عملیات روی آن انجام شده است.

نوع خروجی: `void`

پارامترهای ورودی:

- `$method`: نام کلاس یا متد که بخش آخر آن به‌عنوان نام عملیات ثبت می‌شود.
- `$cls`: نام کلاس مدل مرتبط با لاگ.
- `$ids`: آرایه شناسه رکوردهایی که باید برای آن‌ها لاگ ثبت شود.

نمونه استفاده:



```php
logAdminBatch(
    'App\\Http\\Controllers\\PostController\\destroy',
    Post::class,
    [1, 2, 3]
);
```


## gfx

این تابع مقادیر تنظیمات گرافیکی قالب (Theme Engine) را از مدل `Gfx` دریافت می‌کند.

تمام مقادیر جدول به‌صورت یک Collection از نوع کلید و مقدار برگردانده می‌شوند؛ به‌طوری که کلید هر عضو از ستون `key` و مقدار آن از ستون `value` گرفته می‌شود.

این مقادیر معمولاً برای تنظیمات ظاهری قالب مانند رنگ اصلی، رنگ پس‌زمینه، شعاع گوشه‌ها (Border Radius) و سایر ویژگی‌های گرافیکی استفاده می‌شوند.

نوع خروجی: `Illuminate\Support\Collection`

پارامتر ورودی: ندارد.

نمونه استفاده:
```blade
<div class="{{gfx()['container']}}">
```

## queryBuilder

این تابع پارامترهای فعلی درخواست HTTP را به یک Query String تبدیل می‌کند و امکان حذف یک پارامتر مشخص از آن را فراهم می‌کند.

کاربرد اصلی آن حفظ پارامترهای فیلتر، جستجو و سایر تنظیمات صفحه هنگام ساخت لینک‌های مرتب‌سازی است.

اگر مقدار `$except` مشخص شده باشد:

- پارامتر موردنظر از درخواست حذف می‌شود.
- پارامتر `sortType` نیز حذف می‌شود.

در نهایت پارامترهای باقی‌مانده با استفاده از `http_build_query` به رشته Query تبدیل می‌شوند.

نوع خروجی: `string`

پارامتر ورودی:

- `$except`: نام پارامتری که باید از Query String حذف شود. مقدار پیش‌فرض `null` است.

نمونه استفاده:



```php
$query = queryBuilder('sort');
```

نمونه استفاده در Blade:



```php
@foreach($cols as $col)
    <th>
        <a href="?sort={{ $col }}{{ sortSuffix($col) }}&{{ queryBuilder('sort') }}">
            {{ __($col) }}
        </a>
    </th>
@endforeach
```

در این مثال، پارامترهای فعلی صفحه مانند فیلترها و جستجو حفظ می‌شوند، اما پارامتر `sort` و `sortType` برای ساخت لینک جدید حذف می‌شوند.

## sluger

این تابع یک متن را به Slug مناسب برای استفاده در URL تبدیل می‌کند.

مراحل تبدیل عبارت‌اند از:

- جایگزینی برخی کاراکترهای خاص با معادل انگلیسی آن‌ها:
    - `&` به `and`
    - `+` به `plus`
    - `@` به `at`
    - `*` به `star`
- جایگزینی کاراکترهای غیرمجاز با کاراکتر تعیین‌شده در `$replace_char`.
- تبدیل و انتقال کاراکترها با استفاده از `iconv`.
- حذف کاراکتر جایگزین از ابتدا و انتهای متن.
- حذف کاراکترهای جایگزین تکراری.
- تبدیل حروف به حروف کوچک.
- محدود کردن طول خروجی به ۱۲۰ کاراکتر.

اگر خروجی خالی باشد، مقدار `N-A` برگردانده می‌شود.

نوع خروجی: `string`

پارامترهای ورودی:

- `$name`: متنی که باید به Slug تبدیل شود.
- `$replace_char`: کاراکتری که برای جایگزینی کاراکترهای غیرمجاز استفاده می‌شود. مقدار پیش‌فرض `-` است.

نمونه استفاده:



```php
$slug = sluger('Hello World & Laravel');
// hello-world-and-laravel

$slug = sluger('Hello World', '_');
// hello_world
```

## lastCrump

این تابع آخرین بخش مسیر Breadcrumb پنل مدیریت را تولید و مستقیماً در خروجی HTML چاپ می‌کند.

با بررسی نام Route فعلی، بخش‌های مختلف مسیر را تشخیص داده و متناسب با آن‌ها عنوان، آیکون و لینک موردنیاز را تولید می‌کند.

رفتار تابع بر اساس نوع Route:

- اگر تعداد بخش‌های نام Route دقیقاً ۳ نباشد، آخرین بخش Route را به‌عنوان عنوان Breadcrumb نمایش می‌دهد.
- اگر Route مربوط به `home` باشد، چیزی چاپ نمی‌کند.
- اگر بخش آخر Route یکی از `all`، `index` یا `list` باشد، عنوان جمع‌شده نام بخش قبلی را نمایش می‌دهد.
- برای سایر Routeها، ابتدا لینک بازگشت به صفحه `index` همان بخش را ایجاد می‌کند و سپس عنوان و آیکون متناسب با عملیات را نمایش می‌دهد.

عملیات شناخته‌شده شامل موارد زیر است:

- `create`: افزودن
- `edit`: ویرایش
- `show`: نمایش
- `sort`: مرتب‌سازی
- `trashed`: موارد حذف‌شده
- `design`: طراحی

نوع خروجی: `void`

پارامتر ورودی: ندارد.

نحوه استفاده:

این تابع مستقیماً در فایل Blade فراخوانی می‌شود و نیازی به دریافت خروجی آن نیست.


```php
<ol class="breadcrumb">
    @php
        lastCrump();
    @endphp
</ol>
```

## showCatNestedControl

این تابع برای نمایش دسته‌بندی‌ها یا گروه‌ها به‌صورت درختی (Nested) همراه با Checkbox در پنل مدیریت استفاده می‌شود.

با دریافت لیست دسته‌بندی‌ها، ساختار والد و فرزند آن‌ها را به‌صورت بازگشتی بررسی کرده و خروجی HTML شامل تگ‌های `ul`، `li` و `input` تولید می‌کند.

دسته‌بندی‌هایی که شناسه آن‌ها در آرایه `$checked` وجود داشته باشد، به‌صورت پیش‌فرض انتخاب‌شده نمایش داده می‌شوند.

نوع خروجی: `string` (HTML)

پارامترهای ورودی:

- `$cats`: مجموعه دسته‌بندی‌ها یا گروه‌ها که هر عضو باید دارای فیلدهای `id`، `parent_id` و `name` باشد.
- `$checked`: آرایه شناسه دسته‌بندی‌هایی که باید Checkbox آن‌ها انتخاب‌شده باشد. مقدار پیش‌فرض `[]` است.
- `$parent`: شناسه والد برای تولید زیرشاخه‌ها. مقدار پیش‌فرض `null` است.

نمونه استفاده:
```php
{!! showCatNestedControl($categories, [1, 3, 5]) !!}
```

در این مثال دسته‌بندی‌های دارای شناسه ۱، ۳ و ۵ به‌صورت انتخاب‌شده نمایش داده می‌شوند.

## showCatNested

این تابع برای نمایش دسته‌بندی‌ها یا گروه‌ها به‌صورت درختی (Nested) با استفاده از لینک استفاده می‌شود.

ساختار والد و فرزند دسته‌بندی‌ها را به‌صورت بازگشتی بررسی کرده و خروجی HTML شامل تگ‌های `ul`، `li` و `a` تولید می‌کند.

دسته‌بندی‌هایی که مقدار فیلد `hide` آن‌ها برابر `true` باشد، نمایش داده نمی‌شوند.

لینک هر دسته‌بندی نیز با استفاده از متد `webUrl()` همان دسته‌بندی ساخته می‌شود.

نوع خروجی: `string` (HTML)

پارامترهای ورودی:

- `$cats`: مجموعه دسته‌بندی‌ها یا گروه‌ها که هر عضو باید دارای فیلدهای `id`، `parent_id`، `name`، `hide` و متد `webUrl()` باشد.
- `$parent`: شناسه والد برای تولید زیرشاخه‌ها. مقدار پیش‌فرض `null` است.

نمونه استفاده:
```php
{!! showCatNested($categories) !!}
```

برای نمایش دسته‌بندی‌ها همراه با زیرشاخه‌های آن‌ها استفاده می‌شود.

## getModelName

این تابع برای ساخت یک نام قابل نمایش از اطلاعات یک مدل در ساختار Polymorphic استفاده می‌شود.

نام کلاس مدل را از انتهای مقدار `$modelable_type` استخراج کرده و شناسه مدل را به آن اضافه می‌کند.

خروجی شامل نام مدل و شناسه آن است که با کاراکتر `:` از یکدیگر جدا شده‌اند.

نوع خروجی: `string`

پارامترهای ورودی:

- `$modelable_type`: نام کامل کلاس مدل (معمولاً مقدار ستون `modelable_type`).
- `$modelable_id`: شناسه مدل (معمولاً مقدار ستون `modelable_id`).

نمونه استفاده:


```php
getModelName(Post::class, 25);

// Post:25
```

## getModelLink

این تابع برای تولید لینک صفحه نمایش یک مدل در پنل مدیریت بر اساس اطلاعات Polymorphic استفاده می‌شود.

ابتدا نام کلاس مدل را از `$modelable_type` استخراج کرده و به حروف کوچک تبدیل می‌کند.

سپس نام Route موردنظر را با الگوی زیر می‌سازد:

`admin.{model}.show`

اگر Route موردنظر وجود داشته باشد، لینک آن با شناسه `$modelable_id` تولید می‌شود؛ در غیر این صورت رشته خالی برمی‌گرداند.

نوع خروجی: `string`

پارامترهای ورودی:

- `$modelable_type`: نام کامل کلاس مدل.
- `$modelable_id`: شناسه رکورد مدل موردنظر.

نمونه استفاده:


```php
$link = getModelLink(Post::class, 25);
```

در صورتی که Route با نام `admin.post.show` وجود داشته باشد، لینک صفحه نمایش پست با شناسه ۲۵ برگردانده می‌شود.

## modelWithCustomAttrs

این تابع برای دریافت اطلاعات یک مدل Eloquent همراه با Attributeهای محاسباتی (Custom Attributes) استفاده می‌شود.

ابتدا اطلاعات مدل را با `toArray()` دریافت می‌کند، سپس Attributeهای تغییر‌یافته (Mutated Attributes) را استخراج کرده و مقادیر آن‌ها را به آرایه خروجی اضافه می‌کند.

Attribute با نام `translations` از این فرآیند حذف می‌شود.

این تابع برای زمانی کاربرد دارد که بخواهیم اطلاعات مدل را به همراه مقادیر Attributeهای سفارشی آن دریافت کنیم.

نوع خروجی: `array`

پارامتر ورودی:

- `$model`: نمونه‌ای از مدل Eloquent که اطلاعات آن باید استخراج شود.

نمونه استفاده:



```php
$data = modelWithCustomAttrs($post);
```

## getMaxUploadSize

این تابع حداکثر حجم مجاز آپلود فایل در تنظیمات PHP را بر اساس محدودیت‌های سرور محاسبه می‌کند.

دو مقدار زیر بررسی می‌شوند:

- `upload_max_filesize`: حداکثر حجم مجاز برای آپلود یک فایل.
- `post_max_size`: حداکثر حجم مجاز برای کل اطلاعات ارسالی در یک درخواست POST.

در نهایت مقدار کوچک‌تر این دو محدودیت بر اساس بایت برگردانده می‌شود.

نوع خروجی: `int`

پارامتر ورودی: ندارد.

نمونه استفاده:



```php
public function rules(): array
{
    return [
        'title' => ['required', 'string', 'max:255','min:5'],
        // Example: 10485760 (10 MB)
        'clip' => ['nullable', 'mimes:mp4', 'max:'.getMaxUploadSize()], 
    ];
}
```

## returnBytes

این تابع مقدار حجم فایل را که به‌صورت رشته‌ای همراه با واحد اندازه‌گیری وارد شده است، به بایت تبدیل می‌کند.

واحدهای قابل تشخیص عبارت‌اند از:

- `K`: کیلوبایت
- `M`: مگابایت
- `G`: گیگابایت

در صورت نبود واحد، مقدار عددی ورودی بدون تغییر واحد برگردانده می‌شود.

نوع خروجی: `float|int|string`

پارامتر ورودی:

## success

این تابع برای تولید پاسخ JSON موفق در API استفاده می‌شود.

ساختار پاسخ شامل وضعیت موفقیت، پیام، داده‌ها و اطلاعات مربوط به SEO و شبکه‌های اجتماعی است.

اطلاعات متای دریافتی با مقادیر پیش‌فرض ترکیب می‌شوند تا در صورت ارسال نشدن برخی فیلدها، ساختار پاسخ همچنان کامل باشد.

ساختار خروجی شامل موارد زیر است:

- `OK`: وضعیت موفقیت درخواست که همیشه `true` است.
- `message`: پیام پاسخ.
- `data`: اطلاعات اصلی پاسخ.
- `meta`: اطلاعات متای صفحه شامل عنوان، توضیحات و تصویر.
- `og`: اطلاعات Open Graph برای نمایش بهتر لینک در شبکه‌های اجتماعی.
- `twitter`: اطلاعات Twitter Card.
- `canonical_url`: آدرس اصلی صفحه برای موتورهای جستجو.

نوع خروجی: `Illuminate\Http\JsonResponse`

پارامترهای ورودی:

- `$data`: داده اصلی پاسخ. مقدار پیش‌فرض `null` است.
- `$message`: پیام پاسخ. مقدار پیش‌فرض `null` است.
- `$meta`: اطلاعات SEO شامل `title`، `description`، `image` و `secure_image`.
- `$og`: اطلاعات Open Graph شامل `url`، `type`، `site_name`، `description` و `locate`.
- `$twitter`: اطلاعات Twitter Card شامل `card`، `site`، `title`، `description` و `image`.
- `$canonical_url`: آدرس Canonical صفحه. مقدار پیش‌فرض `null` است.
- `$jsonLd`: پارامتر رزروشده برای اطلاعات JSON-LD که در پیاده‌سازی فعلی استفاده نمی‌شود.

نمونه استفاده:
```php
return success(
    $posts,
    'Posts retrieved successfully',
    [
        'title' => 'Latest Posts',
        'description' => 'List of latest posts',
    ],
    [
        'type' => 'website',
    ]
);
```

نمونه استفاده:
```php
if (isGuestMaxAttemptTry('sms', 1, 2)) {
    return [
        'OK' => false,
        'message' => __('You try attempts, Try it a few minutes'),
        'error' => __('You try attempts, Try it a few minutes'),
    ];
}
guestLog('sms');
```

در این مثال، اگر IP فعلی در یک ساعت گذشته حداقل پنج بار برای عملیات `login` تلاش ثبت کرده باشد، درخواست محدود می‌شود.

## extractShortCode

این تابع برای استخراج شناسه‌های موجود در یک Shortcode مشخص از متن استفاده می‌شود.

الگوی Shortcode به شکل زیر است:

text

```text
[KEY:123]
```

تابع تمام شناسه‌های عددی مربوط به کلید مشخص‌شده را استخراج کرده و در قالب آرایه برمی‌گرداند.

اگر Shortcode مطابق الگو در متن وجود نداشته باشد، آرایه خالی برگردانده می‌شود.

نوع خروجی: `array`

پارامترهای ورودی:

- `$key`: نام کلید Shortcode.
- `$txt`: متن حاوی Shortcodeها.

نمونه استفاده:

```php
$ids = extractShortCode('ATTACHED', $content);
```

برای مثال، ورودی زیر:

text

```text
[ATTACHED:12] [ATTACHED:25]
```

خروجی زیر را تولید می‌کند:

```php
['12', '25']
```

## fixShortCode

در حال حاضر Shortcodeهای زیر را پردازش می‌کند:

text

```text
[ATTACHED:123]
```

ابتدا شناسه پیوست‌ها را از متن استخراج می‌کند، سپس اطلاعات فایل‌ها را از مدل Attachment دریافت می‌کند.

اطلاعاتی مانند URL فایل، URL موقت، پسوند، عنوان و حجم فایل در قالب اطلاعات مورد نیاز کامپوننت `live-attach` قرار می‌گیرند.

در نهایت Shortcode با کد کامپوننت جایگزین می‌شود.

نوع خروجی: `string`

پارامتر ورودی:

- `$txt`: متن HTML یا محتوایی که شامل Shortcode پیوست‌ها است.

نمونه استفاده:

```php
$content = fixShortCode($post->content);
```

## getValidMarkup

این تابع برای بررسی اولیه و جایگزینی متغیرهای موجود در کدهای Markup استفاده می‌شود.

ابتدا بررسی می‌کند که طول کد ورودی بیشتر از ۴۵ کاراکتر باشد. اگر طول آن کمتر یا مساوی این مقدار باشد، رشته خالی برمی‌گرداند.

سپس کلیدهای موجود در `$keywords` را به الگوی `%key%` تبدیل کرده و مقادیر مربوطه را در `$markup` جایگزین می‌کند.

نوع خروجی: `string`

پارامترهای ورودی:

- `$markup`: متن یا کد Markup حاوی متغیرهای قابل جایگزینی.
- `$keywords`: آرایه اطلاعات جایگزینی که کلیدهای آن نام متغیرها و مقدار هر عضو شامل فیلد `value` است.

نمونه استفاده:

```php
$markup = getValidMarkup(
    '<title>%title%</title>',
    [
        'title' => ['value' => 'Laravel Website'],
    ]
);
```

## humanValue

این تابع برای تبدیل مقدار یک ویژگی به محتوای قابل نمایش در HTML استفاده می‌شود.

با توجه به نوع ویژگی (`type`)، مقدار ورودی را به شکل مناسب نمایش می‌دهد.

انواع پشتیبانی‌شده:

- `color`: نمایش رنگ در قالب یک عنصر HTML با رنگ پس‌زمینه مشخص.
- `checkbox`: نمایش آیکون تأیید یا رد بر اساس مقدار.
- `select`: تبدیل مقدار انتخاب‌شده به عنوان نمایشی آن.
- `singlemulti`: نمایش عنوان گزینه یا گزینه‌های انتخاب‌شده.
- سایر انواع: نمایش مقدار به‌صورت متن یا برچسب‌های HTML.

در صورت تعریف واحد اندازه‌گیری (`unit`)، آن را به انتهای خروجی اضافه می‌کند.

مقادیر متنی با `e()` Escape می‌شوند تا هنگام قرار گرفتن در HTML به‌عنوان کد اجرا نشوند.

نوع خروجی: `string`

پارامترهای ورودی:

- `$prop`: مدل یا آبجکت ویژگی که باید شامل اطلاعاتی مانند `type`، `datas` و `unit` باشد.
- `$value`: مقدار ویژگی که باید به شکل مناسب نمایش داده شود.

نمونه استفاده:

```php
echo humanValue($prop, $productValue);
```

## isValidJsonLd

این تابع برای بررسی اعتبار ساختار JSON-LD ورودی استفاده می‌شود.

ابتدا بررسی می‌کند که ورودی شامل تگ زیر باشد:

HTMLWrap linesCopy codePreview

```html
<script type="application/ld+json">
```

سپس تمام بلوک‌های JSON-LD موجود در متن را استخراج کرده و اعتبار JSON داخل هرکدام را بررسی می‌کند.

اگر هیچ بلوک معتبری پیدا نشود یا حتی یکی از بلوک‌ها JSON نامعتبر داشته باشد، مقدار `false` برمی‌گرداند.

اگر تمام بلوک‌های پیدا‌شده JSON معتبر داشته باشند، مقدار `true` برمی‌گرداند.

نوع خروجی: `bool`

پارامتر ورودی:

- `$value`: متن HTML حاوی یک یا چند بلوک JSON-LD.

نمونه استفاده:

```php
if (isValidJsonLd($markup)) {
    // Markup is valid
}
```
