# Increment input
این کامپوننت برای انتخاب اعداد با قابلیت افزایش یا کاهش به کار می‌رود

![incerment.png](../../images/incerment.webp)

## How to use

```vue
<increment xname="name" xvalue="110"
 xmax="1000" xmin="0"
></increment>
```

- xname: نام مورد استفاده در فرم
- xvalue: عدد پیش فرض
- xmin: حداقل مقدار
- xmax: حداکثر مقدار
