# Time picker

کامپوننت انتخاب زمان برای فقط انتخاب زمان کاربرد دارد.

![timepicker.png](https://raw.githubusercontent.com/4xmen/xshop-docs/refs/heads/master/images/timepicker.webp)

## چگونگی استفاده

```vue
    <vue-time-picker :am-pm="false"
     xid="timepicker"
     xname="timepicker"
     :xvalue="78360"
     xtitle="Start time"></vue-time-picker>
```

- xid: آی‌دی کامپوننت
- xname: نام مورد استفاده در فرم برای ارسال و ثبت
- xvalue: نمایش زمان به timestamp
- xtitle: عنوان یا placeholder
