# Question

مدل `Question` برای ثبت پرسش مشتریان درباره محصولات استفاده می‌شود. این پرسش‌ها می‌توانند درباره مشخصات محصول، قابلیت‌ها یا خدمات مرتبط با آن باشند؛ برای مثال، آیا محصول خدمات پس از فروش دارد یا عرض شانه‌ی یک لباس چقدر است.

## ساختار داده
| فیلد | نوع | Nullable | توضیحات |
|---|---|---|---|
| `id` | BIGINT UNSIGNED | خیر | شناسه یکتای پرسش |
| `body` | TEXT | خیر | متن پرسش مشتری |
| `customer_id` | BIGINT UNSIGNED | خیر | شناسه مشتری ثبت‌کننده پرسش |
| `answer` | TEXT | بله | پاسخ ثبت‌شده به پرسش؛ می‌تواند خالی باشد |
| `product_id` | BIGINT UNSIGNED | خیر | شناسه محصولی که پرسش درباره آن مطرح شده است |
| `status` | TINYINT | خیر | وضعیت پرسش با مقدار `0` یا `1` |
| `created_at` | TIMESTAMP | بله | زمان ایجاد پرسش |
| `updated_at` | TIMESTAMP | بله | زمان آخرین به‌روزرسانی |

## روابط

- `product()`: رابطه‌ی `belongsTo` با مدل `Product`؛ محصولی که پرسش درباره آن مطرح شده است.
- `customer()`: رابطه‌ی `belongsTo` با مدل `Customer`؛ مشتری ثبت‌کننده پرسش.

## متدها

### `product()`

محصول مرتبط با پرسش را برمی‌گرداند.

### `customer()`

مشتری ثبت‌کننده پرسش را برمی‌گرداند.

## نکات

- پرسش‌ها به یک محصول مشخص متصل هستند و برای پرسش‌های عمومی سایت طراحی نشده‌اند.
- پاسخ در فیلد `answer` ذخیره می‌شود و اختیاری است.
- حذف مشتری یا محصول، طبق محدودیت‌های کلید خارجی دیتابیس، پرسش‌های مرتبط را نیز حذف می‌کند.
- فیلد `status` مقادیر `0` و `1` را می‌پذیرد؛ معنای دقیق هر مقدار در این مستند مشخص نشده است.
