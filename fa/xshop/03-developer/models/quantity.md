# Quantity

مدل `Quantity` موجودی و قیمت هر ترکیب از ویژگی‌های یک محصول را نگه می‌دارد. یک محصول می‌تواند چند رکورد `Quantity` داشته باشد که هرکدام معرف یک حالت قابل فروش از همان محصول هستند.

برای مثال، برای یک محصول مانند iPhone می‌توان ترکیب‌های مختلف ظرفیت، رنگ و نوع سیم‌کارت را در رکوردهای جداگانه ثبت کرد. هر ترکیب می‌تواند موجودی و قیمت مخصوص به خود را داشته باشد.

## جدول `quantities`

| فیلد | نوع | توضیحات |
|---|---|---|
| `id` | BIGINT UNSIGNED | شناسه رکورد موجودی |
| `product_id` | BIGINT UNSIGNED | شناسه محصول مرتبط؛ کلید خارجی به `products.id` |
| `count` | INT UNSIGNED، پیش‌فرض 0 | تعداد موجود از این ترکیب محصول |
| `price` | DECIMAL(20,2)، پیش‌فرض 0 | قیمت این ترکیب از محصول |
| `image` | BIGINT UNSIGNED، nullable | اندیس تصویر محصول که برای نمایش تصویر مرتبط با این ترکیب استفاده می‌شود |
| `data` | LONGTEXT، nullable | اطلاعات ویژگی‌های انتخاب‌شده برای این ترکیب، ذخیره‌شده در قالب JSON |
| `deleted_at` | TIMESTAMP، nullable | زمان حذف نرم رکورد |
| `created_at` | TIMESTAMP، nullable | زمان ایجاد |
| `updated_at` | TIMESTAMP، nullable | زمان آخرین ویرایش |

حذف محصول به‌صورت فیزیکی، طبق تعریف کلید خارجی، باعث حذف رکوردهای مرتبط در `quantities` نیز می‌شود (`ON DELETE CASCADE`).

## رابطه با محصول

متد `product()` رابطه‌ی `belongsTo` با مدل `Product` برقرار می‌کند و محصول مالک این رکورد را برمی‌گرداند.

## اطلاعات ویژگی‌ها (`data`)

فیلد `data` مشخصات مربوط به ترکیب محصول را به‌صورت JSON نگه می‌دارد. کلیدهای این JSON نام فنی ویژگی‌ها (`Prop.name`) هستند و مقادیر آن‌ها، مقدار انتخاب‌شده برای هر ویژگی را مشخص می‌کنند.

برای مثال، یک رکورد می‌تواند ویژگی‌هایی مانند رنگ، ظرفیت حافظه و نوع سیم‌کارت را در خود نگه دارد. این اطلاعات به ویژگی‌های تعریف‌شده برای دسته‌بندی اصلی محصول متصل می‌شوند.

### `getMetaAttribute()`

این accessor مقدار `data` را به اطلاعات ساختاریافته و آماده‌ی نمایش تبدیل می‌کند.

مراحل کار:

1. مقدار JSON ذخیره‌شده در `data` را به آرایه تبدیل می‌کند. اگر نتیجه `null` باشد، آرایه خالی برمی‌گرداند.
2. ویژگی‌های مرتبط با دسته‌بندی اصلی محصول را بر اساس نام‌هایی که در JSON وجود دارند دریافت می‌کند.
3. برای هر ویژگی، اطلاعات زیر را در خروجی قرار می‌دهد:
    - `label`: عنوان ویژگی
    - `human_value`: مقدار آماده‌ی نمایش
    - `type`: نوع ویژگی
    - `value`: مقدار اصلی ذخیره‌شده
4. بر اساس نوع ویژگی، مقدار قابل نمایش را تولید می‌کند:
    - `color`: نشان رنگی HTML
    - `checkbox`: آیکون تأیید یا رد
    - `select` و `singlemulti`: تبدیل مقدار ذخیره‌شده به عنوان گزینه با استفاده از `Prop.datas`
    - سایر انواع: نمایش مقدار متنی یا آرایه‌ای؛ مقدار خالی با `-` جایگزین می‌شود.
5. واحد ویژگی (`unit`) را به `human_value` اضافه می‌کند.

خروجی نهایی، آرایه‌ای از ویژگی‌هاست که با نام فنی هر ویژگی کلیدگذاری شده است.

## کاربرد در فروشگاه

`Quantity` در کنار `Product` و `Prop` سه مسئولیت متمایز دارد:

- `Product`: اطلاعات عمومی و پایه محصول.
- `Prop`: تعریف ویژگی‌ها، نوع ورودی، گزینه‌ها و قواعد نمایش.
- `Quantity`: ثبت ترکیب مشخصی از مقادیر ویژگی‌ها به همراه قیمت و موجودی آن ترکیب.

این تفکیک اجازه می‌دهد چند حالت قابل فروش از یک محصول، بدون ایجاد رکورد محصول جداگانه برای هر حالت، مدیریت شوند.
