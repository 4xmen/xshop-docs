# Transport

مدل `Transport` برای مدیریت شیوه‌های ارسال محصولات استفاده می‌شود؛ مانند پست یا پیک موتوری. هر روش ارسال دارای عنوان، توضیحات، هزینه، آیکون و تنظیمات مربوط به ترتیب نمایش و انتخاب پیش‌فرض است.

## ساختار داده
| فیلد | نوع | Nullable | توضیحات |
|---|---|---|---|
| `id` | BIGINT UNSIGNED | خیر | شناسه یکتای شیوه ارسال |
| `title` | TEXT | خیر | عنوان شیوه ارسال؛ قابل ترجمه |
| `description` | TEXT | بله | توضیحات شیوه ارسال؛ قابل ترجمه |
| `sort` | INT UNSIGNED | خیر | ترتیب نمایش شیوه ارسال؛ مقدار پیش‌فرض `0` |
| `is_default` | TINYINT(1) | خیر | مشخص می‌کند آیا این شیوه ارسال، پیش‌فرض است؛ مقدار پیش‌فرض `0` |
| `price` | DECIMAL(20,2) | خیر | هزینه ارسال؛ مقدار پیش‌فرض `0.00` |
| `icon` | VARCHAR(255) | بله | نام آیکون شیوه ارسال از Remix Icon |
| `deleted_at` | TIMESTAMP | بله | زمان حذف نرم رکورد |
| `created_at` | TIMESTAMP | بله | زمان ایجاد رکورد |
| `updated_at` | TIMESTAMP | بله | زمان آخرین به‌روزرسانی رکورد |

## ویژگی‌ها

### `$translatable`

فیلدهای `title` و `description` به‌عنوان فیلدهای قابل ترجمه تعریف شده‌اند و امکان نمایش عنوان و توضیحات شیوه ارسال به زبان‌های مختلف را فراهم می‌کنند.

## نکات

- عنوان می‌تواند نام روش ارسال، مانند «پست» یا «پیک موتوری»، باشد.
- فیلد `sort` برای تعیین ترتیب نمایش شیوه‌های ارسال استفاده می‌شود.
- فیلد `is_default` مشخص می‌کند کدام روش ارسال به‌صورت پیش‌فرض انتخاب شود.
- **هنگام انتخاب یک شیوه ارسال جدید به‌عنوان پیش‌فرض، شیوه ارسال پیش‌فرض قبلی باید از حالت پیش‌فرض خارج شود و مقدار `is_default` آن به `0` (`false`) تغییر کند.** این رفتار باید در منطق برنامه مدیریت شود؛ ساختار جدول به‌تنهایی یکتا بودن روش پیش‌فرض را تضمین نمی‌کند.
- فیلد `price` مبلغ هزینه ارسال را با دقت اعشاری دو رقم ذخیره می‌کند.
- فیلد `icon` برای انتخاب آیکون از طریق Icon Picker و با استفاده از مجموعه Remix Icon در نظر گرفته شده است.
- فیلد `deleted_at` برای ثبت زمان حذف نرم در نظر گرفته شده است؛ فعال بودن قابلیت Soft Deletes به تنظیمات مدل وابسته است.
