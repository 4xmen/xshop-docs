# Item

مدل `Item` یک آیتم از منو را نگه می‌دارد؛ مثل لینک یک نوشته، محصول، سرفصل یا دسته‌بندی، یا یک لینک مستقیم به مسیر دلخواه.

هر آیتم به یک منو تعلق دارد و می‌تواند آیتم‌های فرزند داشته باشد. نوع آیتم با `kind` مشخص می‌شود و مقصد آن بر اساس نوع، از رابطه `menuable` یا مقدار `meta` به دست می‌آید.

## ساختار جدول `items`

| فیلد | نوع | توضیحات |
|---|---|---|
| `id` | BIGINT UNSIGNED | شناسه آیتم |
| `title` | TEXT | عنوان قابل نمایش آیتم؛ همان Label |
| `menuable_id` | BIGINT UNSIGNED NULL | شناسه موجودیت مقصد در رابطه چندریختی |
| `menuable_type` | VARCHAR(255) NULL | کلاس موجودیت مقصد در رابطه چندریختی |
| `kind` | VARCHAR(255) NULL | نوع آیتم؛ مانند `module` یا `direct` |
| `meta` | TEXT NULL | در حالت `direct`، آدرس لینک مستقیم |
| `parent` | INT UNSIGNED NULL | شناسه آیتم والد برای ساخت منوی تو‌در‌تو |
| `sort` | INT UNSIGNED | ترتیب نمایش آیتم؛ پیش‌فرض `0` |
| `icon` | VARCHAR(255) NULL | نام آیکون Remix Icon |
| `user_id` | BIGINT UNSIGNED | شناسه کاربر مرتبط با آیتم |
| `menu_id` | BIGINT UNSIGNED | شناسه منوی مربوط به آیتم |
| `created_at` | TIMESTAMP NULL | زمان ایجاد |
| `updated_at` | TIMESTAMP NULL | زمان آخرین به‌روزرسانی |

## ویژگی‌ها

### ترجمه عنوان

```php
public $translatable = ['title'];
```

فیلد `title` قابلیت ترجمه دارد و می‌تواند عنوان آیتم را متناسب با زبان جاری نمایش دهد.

### نوع آیتم و مقصد آن

فیلد `kind` مشخص می‌کند لینک آیتم چگونه ساخته شود:

- **`module`**: آیتم به یک موجودیت از طریق رابطه چندریختی `menuable` متصل است؛ مانند نوشته، محصول، سرفصل یا دسته‌بندی.
- **`direct`**: لینک مستقیم از فیلد `meta` خوانده می‌شود و نیازی به موجودیت مقصد ندارد.

در این طراحی، `menuable` مقصدِ مبتنی بر مدل و `meta` مقصدِ مبتنی بر URL است؛ بنابراین این دو روش، دو شیوه متفاوت برای تعیین مقصد آیتم هستند.

## متدها و روابط

### `menu()`

رابطه `belongsTo` با مدل [Menu](menu.md) برقرار می‌کند.

از طریق این رابطه می‌توان منویی را که آیتم به آن تعلق دارد دریافت کرد. کلید خارجی `menu_id` و کلید مرجع `id` است.

### `parent()`

رابطه `belongsTo` با خود مدل `Item` برقرار می‌کند و آیتم والد را از طریق فیلد `parent` پیدا می‌کند.

این رابطه برای ساخت سلسله‌مراتب منو استفاده می‌شود.

### `children()`

رابطه `hasMany` با خود مدل `Item` برقرار می‌کند و تمام آیتم‌هایی را برمی‌گرداند که مقدار `parent` آن‌ها برابر شناسه آیتم جاری است.

### `dest()`

رابطه چندریختی `morphTo` با نام `menuable` برقرار می‌کند و مقصد آیتم را با استفاده از دو فیلد زیر تعیین می‌کند:

- `menuable_type`: کلاس مدل مقصد
- `menuable_id`: شناسه رکورد مقصد

نوع مقصد می‌تواند یکی از مدل‌های پشتیبانی‌شده در فهرست `$mrohps` مدل `Menu` باشد.

### `webUrl()`

آدرس نهایی آیتم منو را بر اساس مقدار `kind` تولید می‌کند.

**برای آیتم‌های `direct`:**

- آدرس از فیلد `meta` خوانده می‌شود.
- اگر قابلیت چندزبانه `app.xlang.active` فعال باشد و زبان جاری با زبان اصلی متفاوت باشد، متد تلاش می‌کند زبان جاری را به آدرس اضافه کند.
- اگر آدرس با `/` شروع شود، پیشوند زبان به ابتدای مسیر اضافه می‌شود.
- در غیر این صورت، آدرس صفحه اصلی از طریق `route('client.welcome')` پیدا می‌شود و با نسخه زبان‌دار آن جایگزین می‌شود.
- در زبان اصلی یا زمانی که قابلیت چندزبانه فعال نیست، مقدار `meta` بدون تغییر برگردانده می‌شود.

**برای آیتم‌های غیر از `direct`:**

متد `webUrl()` موجودیت مقصد را از طریق `dest()` دریافت می‌کند و متد `webUrl()` همان موجودیت را فراخوانی می‌کند.

بنابراین، برای آیتم‌های ماژولی، مدل مقصد باید متد `webUrl()` را ارائه دهد.

## نکات پایگاه داده و پیاده‌سازی

- فیلدهای `menu_id` و `user_id` کلید خارجی دارند و حذف رکوردهای مرجع در صورت وجود آیتم وابسته، به دلیل `ON DELETE RESTRICT` محدود می‌شود.
- فیلد `parent` ایندکس دارد، اما در SQL ارائه‌شده کلید خارجی به `items.id` برای آن تعریف نشده است؛ در نتیجه یکپارچگی رابطه والد و فرزند صرفاً با این تعریف پایگاه داده تضمین نمی‌شود.
- نوع `parent` برابر `INT UNSIGNED` است، در حالی که `id` از نوع `BIGINT UNSIGNED` است. این اختلاف نوع ارزش بررسی دارد.
- در متد `webUrl()`، دسترسی به `$this->meta[0]` فرض می‌کند `meta` مقدار قابل استفاده‌ای دارد. چون `meta` در پایگاه داده nullable است، بهتر است رفتار آیتم‌های `direct` بدون آدرس نیز بررسی شود.
- در مسیر آیتم‌های غیر از `direct`، متد فرض می‌کند مقصد معتبر است؛ اگر `dest()` مقدار `null` برگرداند، فراخوانی `webUrl()` روی آن خطا ایجاد می‌کند.
