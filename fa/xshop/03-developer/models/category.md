# Category

Model reference · `App\Models\Category`

### 1. Model

مدل مدیریت دسته‌بندی‌های محصولات؛ شامل ساختار درختی دسته‌ها، تنظیمات ظاهری، ارتباط با محصولات و تنظیمات SEO و Schema Markup.

### 3. Extra description of table fields

**`categories.name`، `categories.subtitle` و `categories.description`**

نام، زیرعنوان و توضیحات دسته‌بندی را نگهداری می‌کنند. هر سه فیلد قابلیت چندزبانه دارند.

**`categories.slug`**

شناسه متنی یکتای دسته‌بندی است که برای آدرس‌دهی صفحات استفاده می‌شود.

**`categories.icon`**

نام آیکون انتخاب‌شده از طریق Icon Picker مجموعه Remix Icon را نگهداری می‌کند.

**`categories.sort`**

ترتیب نمایش دسته‌بندی را مشخص می‌کند.

**`categories.image`، `categories.svg` و `categories.bg`**

- `image`: تصویر دسته‌بندی.
- `svg`: تصویر وکتور دسته‌بندی که می‌تواند در کنار تصویر اصلی استفاده شود.
- `bg`: تصویر پس‌زمینه دسته‌بندی که می‌تواند در طراحی بخش‌های مختلف Theme کاربرد داشته باشد.

**`categories.parent_id`**

برای ایجاد ساختار درختی دسته‌بندی‌ها استفاده می‌شود. این فیلد شناسه دسته‌بندی والد را نگهداری می‌کند و برای دسته‌های اصلی می‌تواند `NULL` باشد.

**`categories.theme`**

امکان تعریف تنظیمات Theme اختصاصی برای یک دسته‌بندی را فراهم می‌کند. این قابلیت می‌تواند ظاهر دسته‌بندی را از قالب عمومی سایت متمایز کند. جزئیات ساختار و نحوه استفاده از Theme در مستندات [Area](area.md) توضیح داده شده است.

**`categories.canonical`**

آدرس Canonical صفحه را برای مدیریت سیگنال‌های SEO نگهداری می‌کند.

**`categories.hide`**

مشخص می‌کند دسته‌بندی در منوهایی که زیر‌دسته‌ها را نمایش می‌دهند، مخفی شود یا خیر. این فیلد برای کنترل نمایش در منو است و به‌تنهایی به معنی غیرفعال شدن صفحه دسته‌بندی نیست.

**`categories.default_markup`**

Schema Markup پیش‌فرضی را نگهداری می‌کند که برای محصولات زیرمجموعه این دسته‌بندی استفاده می‌شود؛ به‌ویژه زمانی که دسته‌بندی نقش دسته اصلی محصول را دارد.

**`categories.markups`**

Schema Markup مربوط به خود صفحه دسته‌بندی را نگهداری می‌کند. برخلاف `default_markup` که برای محصولات زیرمجموعه است، این فیلد برای ساختار داده‌های صفحه دسته‌بندی کاربرد دارد.

### 4. Methods

**`markupKeywords()`**

فهرست کلمات جایگزین قابل استفاده در Schema Markup را همراه با عنوان و مقدار هر کلمه برمی‌گرداند. برای مثال، `%name%` می‌تواند با نام دسته‌بندی جایگزین شود و `app.name` مقدار نام سایت را از تنظیمات برنامه دریافت کند.

**`bgUrl()`، `imgUrl()` و `svgUrl()`**

آدرس قابل استفاده تصویر پس‌زمینه، تصویر اصلی یا تصویر SVG را برمی‌گردانند. اگر تصویر مربوطه موجود نباشد، لوگوی پیش‌فرض سایت نمایش داده می‌شود.

**`bgOriginalUrl()` و `imgOriginalUrl()`**

آدرس نسخه اصلی تصاویر پس‌زمینه و تصویر دسته‌بندی را برمی‌گردانند؛ برخلاف نسخه‌های معمولی که ممکن است برای نمایش بهینه‌سازی شده باشند.

**`children()`**

رابطه‌ی `hasMany` با همین مدل را بر اساس `parent_id` تعریف می‌کند و دسته‌بندی‌های زیرمجموعه را برمی‌گرداند.

**`getRouteKeyName()`**

مشخص می‌کند Laravel برای Route Model Binding از فیلد `slug` به‌جای `id` استفاده کند.

**`props()`**

رابطه‌ی `belongsToMany` با مدل `Prop` را تعریف می‌کند و ویژگی‌های مرتبط با دسته‌بندی را برمی‌گرداند. برای جزئیات این بخش به مستندات [Prop](prop.md) مراجعه کنید.

**`attachs()`**

لیست پیوست‌های مرتبط با دسته‌بندی را برمی‌گرداند.

**`webUrl()`**

آدرس صفحه دسته‌بندی را برمی‌گرداند و در صورت چندزبانه بودن سایت، اصلاحات مربوط به زبان آدرس را اعمال می‌کند.

**`products()`**

رابطه‌ی `belongsToMany` با مدل `Product` را تعریف می‌کند و محصولات مرتبط با دسته‌بندی را برمی‌گرداند.

**`published($limit = 10, $order = 'id', $dir = 'DESC')`**

فهرست محصولات منتشرشده زیرمجموعه دسته‌بندی را برمی‌گرداند. پارامترها برای تعیین تعداد نتایج، فیلد مرتب‌سازی و جهت مرتب‌سازی استفاده می‌شوند.

**`evaluations()`**

به سیستم امتیازدهی مرتبط با دسته‌بندی دسترسی می‌دهد. برای جزئیات این سیستم به مستندات [Evaluation](evaluation.md) مراجعه کنید.

**`parallelCategories()`**

دسته‌بندی‌های موازی و هم‌خانواده با دسته‌بندی فعلی را برمی‌گرداند.

**`markup()`**

Schema Markup مربوط به دسته‌بندی را نمایش یا تولید می‌کند.
