# Creator

**کاربرد مدل:** این مدل برای تعریف سازنده محصول استفاده می‌شود. بسته به نوع فروشگاه، سازنده می‌تواند برند محصول، مانند سامسونگ یا اپل، یا شخصی مانند مؤلف و مترجم باشد. بنابراین کاربرد آن محدود به برندهای تجاری نیست و می‌توان از آن برای انواع فروشگاه‌ها و کاتالوگ‌های محصول استفاده کرد.

## Table: `creators`

| Field | Type | Nullable | Comment |
|---|---|---|---|
| `id` | BIGINT UNSIGNED | خیر | شناسه یکتای سازنده |
| `name` | TEXT | خیر | نام سازنده |
| `slug` | VARCHAR(128) | خیر | شناسه متنی یکتا برای آدرس سازنده |
| `subtitle` | TEXT | بله | زیرعنوان سازنده |
| `description` | LONGTEXT | بله | توضیحات سازنده |
| `image` | VARCHAR(2048) | بله | تصویر سازنده |
| `parent_id` | INT UNSIGNED | بله | شناسه سازنده والد |
| `canonical` | TEXT | بله | آدرس Canonical صفحه سازنده |
| `sort` | INT | خیر | ترتیب نمایش سازنده |
| `deleted_at` | TIMESTAMP | بله | زمان حذف نرم رکورد |
| `created_at` | TIMESTAMP | بله | زمان ایجاد رکورد |
| `updated_at` | TIMESTAMP | بله | زمان آخرین به‌روزرسانی |
| `markups` | TEXT | بله | تنظیمات Schema Markup صفحه سازنده |

## توضیحات تکمیلی فیلدها

- `name`، `subtitle` و `description`: فیلدهای قابل ترجمه هستند.
- `slug`: مقدار یکتای مورد استفاده برای شناسایی سازنده در آدرس صفحه وب است.
- `image`: تصویر سازنده را مشخص می‌کند؛ نسخه بهینه‌شده و نسخه اصلی تصویر از مسیرهای متفاوتی ارائه می‌شوند.
- `parent_id`: امکان تعریف ساختار سلسله‌مراتبی بین سازندگان را فراهم می‌کند؛ برای مثال، ایجاد سازنده‌های زیرمجموعه یک سازنده دیگر.
- `canonical`: آدرس Canonical صفحه سازنده را نگه می‌دارد و برای مدیریت آدرس ترجیحی صفحه در موتورهای جست‌وجو قابل استفاده است.
- `sort`: ترتیب نمایش سازنده را مشخص می‌کند.
- `markups`: تنظیمات Schema Markup اختصاصی صفحه سازنده را نگه می‌دارد.

## Methods

### `$translatable = ['name', 'subtitle', 'description']`

مشخص می‌کند که نام، زیرعنوان و توضیحات سازنده از سیستم ترجمه مدل استفاده می‌کنند و می‌توانند در زبان‌های مختلف مقادیر متفاوتی داشته باشند.

### `markupKeywords()`

متغیرهای قابل استفاده در تنظیمات Schema Markup سازنده را به‌صورت آرایه‌ای از عنوان و مقدار ارائه می‌کند.

متغیرهای تعریف‌شده در کد فعلی:

- `app.name`: نام برنامه از تنظیمات `config('app.name')`.
- `name`: نام سازنده از فیلد `name` مدل.

### `findOrCreate($values, $type = null, $locale = null)`

سازنده را بر اساس یک رشته، آرایه یا مجموعه‌ای از مقادیر پیدا می‌کند یا در صورت نیاز می‌سازد. این متد برای ساده‌سازی ثبت سازنده هنگام ایجاد یا ویرایش محصول کاربرد دارد و امکان کار با چند سازنده در یک فراخوانی را فراهم می‌کند.

- اگر مقدار ورودی یک نمونه از `Creator` باشد، همان نمونه استفاده می‌شود.
- در غیر این صورت، هر مقدار به `findOrCreateFromString()` سپرده می‌شود.
- اگر ورودی رشته باشد، یک سازنده برمی‌گرداند؛ در غیر این صورت، مجموعه نتایج را برمی‌گرداند.

### `findFromString($name, $type = null, $locale = null)`

سازنده موجود را بر اساس نام یا `slug` در زبان مشخص‌شده جست‌وجو می‌کند. اگر زبان تعیین نشده باشد، زبان جاری مدل استفاده می‌شود. در صورت پیدا نشدن سازنده، مقدار `null` برمی‌گردد.

پارامتر `$type` در نسخه فعلی کد در شرط جست‌وجو استفاده نمی‌شود.

### `findOrCreateFromString($name, $type = null, $locale = null)`

سازنده را بر اساس نام یا `slug` جست‌وجو می‌کند و اگر وجود نداشته باشد، رکورد جدیدی می‌سازد. هنگام ساخت، نام در زبان انتخاب‌شده ذخیره می‌شود و `slug` با استفاده از تابع `sluger()` تولید می‌شود.

پارامتر `$type` در نسخه فعلی کد برای ساخت رکورد نیز استفاده نمی‌شود.

### `children()`

رابطه `hasMany` با مدل `Creator` را از طریق فیلد `parent_id` تعریف می‌کند و سازندگان زیرمجموعه این سازنده را برمی‌گرداند.

### `getRouteKeyName()`

فیلد `slug` را به‌عنوان کلید مسیریابی مدل تعیین می‌کند تا سازنده از طریق شناسه متنی آن در Routeها شناسایی شود.

### `imgUrl()`

آدرس نسخه بهینه‌شده تصویر سازنده را برمی‌گرداند. اگر تصویر تعریف نشده باشد، آدرس لوگوی پیش‌فرض سایت را برمی‌گرداند.

### `imgOriginalUrl()`

آدرس نسخه اصلی تصویر سازنده را برمی‌گرداند. اگر تصویر تعریف نشده باشد، آدرس لوگوی پیش‌فرض سایت را برمی‌گرداند.

### `attachs()`

رابطه چندریختی (`morphMany`) با مدل [Attachment](attachment.md) را تعریف می‌کند و پیوست‌های مرتبط با سازنده را برمی‌گرداند.

### `webUrl()`

آدرس صفحه عمومی سازنده را با استفاده از Route مربوط به `client.creator` می‌سازد و با `fixUrlLang()` زبان آدرس را تنظیم می‌کند.

### `products()`

رابطه چندبه‌چند (`belongsToMany`) با مدل [Product](product.md) را تعریف می‌کند و محصولات مرتبط با سازنده را برمی‌گرداند.

### `evaluations()`

ارزیابی‌های مرتبط را از مدل [Evaluation](evaluation.md) دریافت می‌کند. این متد ارزیابی‌های عمومی فاقد ارتباط اختصاصی، ارزیابی‌های مربوط به نوع `Creator` بدون شناسه مشخص و ارزیابی‌های اختصاصی همین سازنده را در نتیجه قرار می‌دهد.

### `parent()`

رابطه `belongsTo` با مدل `Creator` را از طریق `parent_id` تعریف می‌کند و سازنده والد را برمی‌گرداند.

### `markup()`

Schema Markup مربوط به صفحه سازنده را تولید یا برمی‌گرداند تا اطلاعات ساختاریافته این صفحه برای موتورهای جست‌وجو ارائه شود.
