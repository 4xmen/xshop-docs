# Image

مدیریت تصاویر داخل گالری. هر رکورد به یک گالری و یک کاربر مرتبط است و اطلاعاتی مانند عنوان نمایشی تصویر و ترتیب نمایش آن را نگهداری می‌کند. فایل تصویر از طریق Media Library مدیریت می‌شود.

## جدول `images`

| فیلد | نوع | Nullable | توضیحات |
|---|---|---|---|
| `id` | BIGINT UNSIGNED | خیر | شناسه یکتای تصویر |
| `gallery_id` | BIGINT UNSIGNED | خیر | شناسه گالری مرتبط؛ مرتبط با جدول `galleries` |
| `user_id` | BIGINT UNSIGNED | خیر | شناسه کاربر مرتبط؛ مرتبط با جدول `users` |
| `title` | TEXT | بله | عنوان یا کپشن تصویر |
| `sort` | INT UNSIGNED | خیر | ترتیب نمایش تصویر؛ مقدار پیش‌فرض `0` |
| `created_at` | TIMESTAMP | بله | تاریخ ایجاد |
| `updated_at` | TIMESTAMP | بله | تاریخ آخرین ویرایش |

## ویژگی‌ها و متدها

### `$translatable`

فیلد `title` قابلیت ذخیره‌سازی و بازیابی ترجمه‌شده دارد.

### `$guarded`

مقدار آرایه خالی (`[]`) به این معناست که هیچ فیلدی در مدل به‌صورت صریح از Mass Assignment محافظت نشده است؛ بنابراین هنگام استفاده از `create()` یا `fill()` باید ورودی‌ها به‌درستی اعتبارسنجی و کنترل شوند.

### `gallery()`

رابطه `belongsTo` با مدل [Gallery](gallery.md) برقرار می‌کند و گالری مرتبط با تصویر را برمی‌گرداند.

### `registerMediaConversions(Media $media = null): void`

تبدیل‌ها و بهینه‌سازی‌های رسانه‌ای تصویر را تعریف می‌کند:

- `image-image`: تبدیل تصویر همراه با بهینه‌سازی.
- `githumb`: تصویر بندانگشتی با ابعاد تنظیم‌شده از طریق `gallery_thumb`؛ تصویر برش داده و بهینه‌سازی می‌شود و فرمت آن از تنظیمات `optimize` گرفته می‌شود.
- در صورت فعال بودن تنظیم `watermark`، واترمارک لوگو با موقعیت، اندازه و شفافیت قابل تنظیم روی تصویر بندانگشتی قرار می‌گیرد.

تبدیل `githumb` با `nonQueued()` بدون قرار گرفتن در صف پردازش رسانه‌ای تعریف شده است.

### `imgurl()`

آدرس تصویر بندانگشتی تصویر را از Media Library دریافت می‌کند. اگر رسانه‌ای برای مدل وجود نداشته باشد، آدرس لوگوی پیش‌فرض سایت را برمی‌گرداند.

### `imgOriginalUrl()`

آدرس نسخه اصلی اولین رسانه مرتبط با مدل را برمی‌گرداند. اگر رسانه‌ای وجود نداشته باشد، آدرس لوگوی پیش‌فرض سایت بازگردانده می‌شود.
