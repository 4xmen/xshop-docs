# GFX

مدیریت تنظیمات گرافیکی و ظاهری سایت. این تنظیمات از طریق Seeder اولیه ایجاد می‌شوند و بخش‌های مختلف قالب، از جمله Theme و Segment، از آن‌ها استفاده می‌کنند. مقادیر تنظیمات در فایل `client.scss` به‌صورت CSS Variable در دسترس قرار می‌گیرند تا ظاهر بخش‌های مختلف سایت از یک مجموعه تنظیمات مشترک پیروی کند.

رکوردهای اولیه توسط Seeder ساخته می‌شوند و در روند فعلی، تنظیمات موجود ویرایش می‌شوند؛ افزودن یا حذف تنظیمات در جریان معمول استفاده از سیستم انجام نمی‌شود.

## جدول `gfxes`

| فیلد | نوع | Nullable | توضیحات |
|---|---|---|---|
| `id` | BIGINT UNSIGNED | خیر | شناسه یکتای تنظیم |
| `key` | VARCHAR(255) | خیر | کلید یکتای تنظیم برای دسترسی به مقدار آن در کد؛ مانند `background` |
| `label` | VARCHAR(255) | خیر | عنوان قابل نمایش تنظیم؛ مانند `Primary color` |
| `system` | TINYINT(1) | خیر | نشانگر تنظیم سیستمی؛ کاربرد دقیق آن در منطق فعلی هنوز مشخص نشده است |
| `value` | LONGTEXT | خیر | مقدار تنظیم گرافیکی |
| `created_at` | TIMESTAMP | بله | تاریخ ایجاد |
| `updated_at` | TIMESTAMP | بله | تاریخ آخرین ویرایش |

## تنظیمات اولیه

مقادیر زیر توسط Seeder ایجاد می‌شوند:

| `key` | `label` | مقدار اولیه | کاربرد |
|---|---|---|---|
| `background` | `background color` | `#eeeeee` | رنگ پس‌زمینه |
| `primary` | `Primary color` | `#03b2b5` | رنگ اصلی قالب |
| `secondary` | `Secondary color` | `#0064c2` | رنگ ثانویه قالب |
| `text` | `Text color` | `#111111` | رنگ متن |
| `dark` | `Theme mode` | `0` | تنظیم حالت ظاهری قالب |
| `border-radius` | `Border radius` | `7px` | شعاع گردی گوشه‌ها |
| `shadow` | `Shadow` | `2px 2px 4px #777777` | تنظیم سایه |
| `container` | `Container` | `container` | مقدار مربوط به کلاس یا نوع Container |
| `font` | `font` | `Vazirmatn` | فونت قالب |

## نحوه استفاده

- **`key`:** شناسه متنی و یکتای تنظیم است و دسترسی به تنظیم را خواناتر می‌کند؛ برای مثال، جست‌وجو بر اساس `key = background` به‌جای وابستگی به شناسه عددی رکورد.
- **`label`:** عنوان تنظیم است و می‌تواند برای نمایش آن در رابط مدیریت استفاده شود.
- **`value`:** مقدار قابل ویرایش تنظیم را نگهداری می‌کند. نوع مقدار به ماهیت تنظیم بستگی دارد؛ برای نمونه، رنگ‌ها به شکل کد رنگ، شعاع گوشه‌ها به شکل مقدار CSS و فونت به شکل نام فونت ذخیره می‌شود.
- **CSS Variables:** مقادیر تنظیمات در `client.scss` به‌صورت متغیرهای CSS در اختیار قالب قرار می‌گیرند تا Theme و Segment بتوانند از آن‌ها استفاده کنند.
- **`system`:** این فیلد در ساختار جدول وجود دارد، اما معنای دقیق آن و تأثیرش بر امکان ویرایش یا مدیریت تنظیمات، بر اساس اطلاعات فعلی قابل تعیین نیست.

## نکات طراحی

- فیلد `key` دارای محدودیت یکتا بودن است؛ بنابراین هر تنظیم باید کلید متمایز خود را داشته باشد.
- تنظیمات اولیه از طریق Seeder تأمین می‌شوند و تغییر مقادیر آن‌ها، روش معمول سفارشی‌سازی ظاهر سایت است.
- فیلد `value` از نوع `LONGTEXT` است تا بتواند مقادیر متنی با قالب‌های متفاوت را نگهداری کند.
