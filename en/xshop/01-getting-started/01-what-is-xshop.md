# What Is xShop?

An open-source Laravel-based system that lets you quickly set up a shop, a blog, or a client's website with minimal configuration and enjoy its benefits.

## Core Features and Differentiators

- **Exceptional flexibility** across almost every dimension, dramatically reducing the need to modify code.
- **Developer-friendly**: built-in tools in the core allow you to add custom code to the system as quickly as possible.
- **Native multilingual support**: choose a language and run a multilingual site with confidence.
- **SEO focus**: the search-engine-friendly architecture resolves most technical SEO issues out of the box.
- **WordPress/WooCommerce migration** capability.
- **Highly customizable theme system**: you can change the site's appearance in any language at any time without hassle.

## Why Did We Create xShop?

After years of coding and building various websites, I discovered many painful boilerplate issues. Leveraging that experience, we built a maximally flexible, boilerplate-reduced system and released it to the open-source community under the GPL license.

### Does xShop Claim to Be Perfect?

No. Such a claim would be wildly exaggerated and unrealistic. However, we strive to identify and fix bugs quickly. Feel free to test us by opening an Issue.
