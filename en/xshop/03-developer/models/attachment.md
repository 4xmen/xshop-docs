# Attachment - Managing Attachments

![attachment.webp](../../images/attachment.webp)

The Attachment section is used to upload and manage files intended to be displayed in site content, made available for users to download, or attached to different parts of the site, such as posts and products.

On this page, you can enter file information, specify how it should be displayed on the site, and, if needed, assign it to a specific section of the site.

## 1. Tips - Page guide

Tips on using attachments are displayed at the top of the sidebar:

- If you do not want the file to appear in the site's public attachment list and it is only used for attaching to other sections, disable **Is fillable**.
- Premium files are intended for customers to download after payment. These files should not be made available to all users like regular files.

## 2. Title, Slug, and Subtitle - Attachment information

### Title

Enter the file title. This title helps you identify the attachment in the admin panel and is used in sections where the file name is displayed.

For example: `News manifest`

### Slug

The attachment's text identifier, used to create its URL. This value is usually generated from the file title.

For example: `news-manifest`

Changing this value may also change the attachment URL, so it is best not to change it unnecessarily after publication.

### Subtitle

Enter a brief description of the file here. The subtitle can provide the user with additional information about the title.

For example, if the attachment is a training file, you can enter its subject or version here.

## 3. Description - Attachment description

You can enter a more detailed description of the file here. The text editor lets you format content and use common text-editing features.

Use this section to describe the file's content, introduce its purpose, or provide instructions for downloading and using it.

## 4. File - Uploading and downloading the file

Upload the attachment's main file here. After uploading, information such as the file name, extension, and size is displayed.

### Download

The Download button lets you download the uploaded file from the admin panel. Use it to download the file and check its integrity or contents.

### Short Code

After the file is saved, a unique code labeled Short Code is displayed; for example:

`[ATTACHED:2]`

You can copy this code and use it in a post's content or in a supported text section.

When the content is displayed on the site, the code is replaced with output appropriate to the file type:

- **Image:** The image itself is displayed.
- **Audio file:** An audio player is displayed so the user can play the file.
- **Video:** A video player is displayed.
- **Other files:** A download link for the file is displayed.

For example, to place an audio file within an article, simply enter its Short Code at the desired location in the content.

This method lets you place a file in site content without manually entering code to display an image, player, or download link.

## 5. Is fillable - Display in the public list

This option specifies whether the attachment is displayed in the site's public attachment list.

- **Enabled:** The attachment can be displayed in the site's public attachment list.
- **Disabled:** The attachment is kept for use in other parts of the site without needing to appear in the public attachment list.

For example, if you uploaded a file only to use within an article and do not want it to appear separately in the attachment list, disable this option.

Disabling this option does not, by itself, restrict direct access to the file; this setting controls whether it appears in the public list.

## 6. Is premium - Premium attachment

This option is for files that require purchase or special access to download.

For example, you can designate a training file, exclusive catalog, or downloadable document as a premium attachment so that it is intended for customers after payment.

- **Enabled:** The attachment is designated as a premium file.
- **Disabled:** The attachment is treated as a regular file.

Note that enabling this option does not, by itself, manage purchases or download permissions; actual access to the file must be controlled by the site's purchase and permission mechanisms.

## 7. Attaching - Attaching an attachment to site sections

Use this section to attach the file to a specific entity on the site, such as a post, product, or gallery.

This feature is useful when you want the file to be recognized as an attachment to a specific section, rather than simply exist as a standalone file on the site.

### Group

This section displays the section or entity related to the attachment. Depending on the type of attachment, you may first need to select the desired destination.

### Search

Use the search field to find the entity you want to attach the file to.

For example, if you want to attach a PDF file to a post, search for and select the desired post.

Attachments can be connected to sections such as:

- Products
- Posts
- Groups
- Categories
- Clips
- Galleries
- Creators

After selecting the destination and saving the changes, the file will be associated with the selected entity.

**Note:** Attaching a file to a post or product differs from inserting its Short Code into the content. Attaching establishes a relationship between the file and that entity; the Short Code is used to place the file's output at a specific location in the content.

## 8. Saving changes

After entering the information, uploading the file, and configuring the required options, click the Save button to record the changes.

Before saving, check that the title and description are correct, the intended file has been uploaded, and the options for public display, premium status, and attachment to site sections are configured as needed.

## Pre-save checklist

- The file title and subtitle have been entered.
- Any necessary file description has been added.
- The correct file has been uploaded.
- If the file needs to be used in site content, its Short Code is available.
- Its display status in the public list has been specified.
- If needed, the file's premium status has been configured.
- If the file belongs to a post, product, or another section, the attachment destination has been selected.
- The changes have been saved.
