# VisitorCounter Middleware

This Middleware records and updates information about website visitors. In addition to collecting visit data, it manages guest users' access to the website when maintenance mode is active. The recorded information can be used to review visit statistics, identify the browsers and operating systems in use, analyze how users arrive at the website, and identify the most visited pages.

For each request, the Middleware first checks whether a visitor with the current IP address has a record from within the past hour. If no record meets these conditions, a new record is created in the visitors table. This record stores information such as the IP address, browser, operating system, browser version, referring domain, search engine keywords, whether a mobile device is being used, and the name of the requested page's Route. This information is extracted using the utilities available in the `TVisitor` class.

If a visitor with the same IP address is identified within the past hour, the existing record is updated. In this case, the `visit` counter is incremented by one, and the current page's Route name is also saved in the record. This way, visitor information is updated in the existing record instead of creating a new record for every request.

In this Middleware, visitor identification is based on a combination of the IP address and the record's last update time. Therefore, this mechanism does not definitively identify individuals or distinct sessions: multiple users sharing an IP address may be grouped into one record, or a user may be recorded in a new record after more than an hour has passed since the last update. Additionally, in this implementation, the `visit` counter is incremented for each eligible request that updates a record and does not necessarily correspond to the number of distinct visits or pages viewed by one person.

After recording or updating the information, the Middleware checks the website's maintenance mode status. If the `under` setting is `1` and the request belongs to an unauthenticated user, that user is redirected to the maintenance page. Otherwise, the request proceeds through the normal processing flow. Visitor information is therefore recorded before this restriction is applied, and guest users' requests can also be included in visit statistics when maintenance mode is active.

Overall, `VisitorCounter` is responsible for recording and updating visitor information and providing basic data for analyzing website traffic. This Middleware also serves as one of the points where maintenance mode restrictions are applied to unauthenticated users. The collected information can be used in analytics and administrative sections, but the accuracy of the analysis depends on the limitations of IP-based identification and how visitor information is extracted.
