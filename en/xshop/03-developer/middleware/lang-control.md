# LangControl Middleware

This Middleware manages the language for the website's visitor-facing sections. Its purpose is to determine which language to use when processing a request so that page content, translations, and language-dependent information are loaded correctly. The language can be specified by the first segment of the page URL; otherwise, the default language defined in the application settings is used.

In this structure, the language can appear at the beginning of the URL as a two-letter code. For example, `/fa/articles` indicates a request for the articles page in the `fa` language. The Middleware first checks the initial URL segment and, if it consists of two English letters, checks for a corresponding translation file in `resources/lang`. The request language is considered valid, and the application language is changed, only if the corresponding translation file exists.

After determining the language, its value is also saved in the user's session. This makes the selected language available to other parts of the application and keeps the request's language information accessible for subsequent processing. A property named `set_lang` is also added to the request attributes so that other parts of the application can use it to determine whether the language was specified through the URL. This property is only a request-level marker and does not, by itself, change the behavior of other parts of the application; its use depends on how the other components are implemented.

If the URL begins with a language code but the corresponding translation file does not exist, the request is redirected to the visitor-facing welcome route. Conversely, if the URL does not begin with a two-letter language code, the Middleware retrieves and applies the application's default language from the `app.locale` setting. Therefore, the request language is determined by the URL structure and the existence of a translation file; if the language is not specified in the URL, the application falls back to its default language.

Alongside the application's content translation system, including the `spatie/laravel-translatable` package, this Middleware plays an important role in determining the language used to display information. The `spatie/laravel-translatable` package provides a way to store and retrieve multilingual translations for model fields. Therefore, correctly setting the application language before processing a request is important so that components dependent on the current language receive information in the expected language. However, this Middleware does not translate model fields itself; its responsibility is limited to setting the current language and providing the conditions needed to process translations correctly.

Overall, `LangControl` is a point in the request processing flow where the language for visitor-facing pages is determined based on the URL or the application's default settings. This mechanism helps maintain consistency in the display of multilingual content and, alongside the model translation system, provides the conditions for loading information in the selected language.
